CHROME · EDGE · FIREFOX

DEC DOCX dans ton navigateur

Sélectionne un texte sur une page, ouvre l’extension et choisis « Copier la sélection et ouvrir ». Le texte reste dans le presse-papiers de l’appareil ; colle-le ensuite dans DEC DOCX.

Télécharger l’extension

Chrome et Edge

  1. Décompresse l’archive téléchargée.
  2. Ouvre chrome://extensions ou edge://extensions.
  3. Active le mode développeur.
  4. Choisis Charger l’extension non empaquetée et sélectionne le dossier décompressé.

Firefox

  1. Ouvre about:debugging#/runtime/this-firefox.
  2. Choisis Charger un module complémentaire temporaire.
  3. Sélectionne le fichier manifest.json.

Chrome et Edge n’autorisent l’installation directe et permanente hors boutique que dans des environnements administrés. Firefox retire les extensions temporaires au redémarrage. Une distribution automatique demandera ensuite une publication dans les boutiques officielles.
