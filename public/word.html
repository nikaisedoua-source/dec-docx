DComplément Microsoft Word

Prépare tes chapitres sans quitter Word.

Sélectionne les versets dans un document Word, lance DEC DOCX depuis le panneau, complète le chapitre puis génère le fichier. Le DOCX mis en forme revient directement à la place de la sélection.

Télécharger le complément Ouvrir Word sur le Web

Installation personnelle dans Word

  1. Dans Word, ouvre Accueil → Compléments → Autres paramètres → Charger mon complément.
  2. Choisis le manifeste téléchargé ci-dessus et ajoute DEC DOCX.
  3. Sélectionne les versets, ouvre Contrôler avec DEC DOCX, puis lance l’envoi.
  4. Complète les renseignements du chapitre dans DEC DOCX et génère le document pour remplacer la sélection.

Le panneau reprend le style de Microsoft Office. L’insertion directe est prise en charge dans Word sur le Web, Windows et macOS et les documents transférés ne dépassent pas 4 Mo. L’administrateur Microsoft 365 peut aussi déployer le complément pour un compte ou une équipe.

Sur iPhone

La version Web DEC DOCX s’ouvre dans Safari et peut être ajoutée à l’écran d’accueil. Génère le DOCX puis ouvre-le dans l’app Word pour iPhone. Le panneau Office personnalisé est destiné à Word sur le Web et sur ordinateur.

Si le chargement personnel est désactivé

Cette option dépend de la politique du compte Microsoft 365. L’administrateur peut publier le manifeste depuis Centre d’administration Microsoft 365 → Paramètres → Applications intégrées → Déployer un complément.
