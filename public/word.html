COMPLÉMENT MICROSOFT WORD

DEC DOCX directement dans Word

Le panneau gratuit permet de lire le texte sélectionné, d’ouvrir DEC DOCX et de réinsérer le texte contrôlé dans le document Word.

Télécharger le manifeste Word corrigéVoir le panneau

Installation personnelle

  1. Supprime d’abord l’ancienne version désactivée de DEC DOCX dans Word.
  2. Télécharge le nouveau fichier manifest.xml.
  3. Dans Word sur le Web, ouvre un document puis Accueil → Compléments → Autres paramètres → Charger mon complément.
  4. Sélectionne le nouveau manifeste, puis ouvre Contrôler avec DEC DOCX.

Le manifeste 1.1.1 est conforme au schéma Microsoft Office, ses ressources sont hébergées en HTTPS et aucune clé payante n’est nécessaire.

Si « Charger mon complément » est désactivé

Cette option est alors bloquée par la politique du compte Microsoft 365. Le propriétaire ou l’administrateur doit déployer le manifeste dans Centre d’administration Microsoft 365 → Paramètres → Applications intégrées → Déployer un complément, pour toi uniquement ou pour le groupe choisi. DEC DOCX ne peut pas contourner cette règle Word.
